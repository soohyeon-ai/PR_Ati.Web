자주 묻는 질문

ATI Biosystems는 ATI의 자동화 기술을 바탕으로 Bio 실험실 자동화에 도전하기 위해 2010년부터 프로젝트를 시작한 조직/브랜드입니다.

연도별로 개발 장비가 정리되어 있습니다.

연도내용
2016세포 자동화 장비 시제품 개발 및 제작
2018플라스크 기반 자동 세포 배양 장비 개발 및 제작
2020플레이트 기반 자동 Cell expansion 장비 개발 및 제작
2022Isolator 프레임의 자동 NK 세포 배양 장비 개발 및 제작
2024GMP 환경에 준하는 자동 세포 배양 장비 개발 중

세포 배양 자동화 장비를 단계적으로 고도화해온 내용입니다.

구성 모듈: 디캐퍼, 그리퍼, Gantry robot, 5000ul pipette 대응 ADP, 자동 원심분리기, Vision deck, 자동 실시간 현미경, 소모품 저장소, Cell counter, Waste 처리 기술 등이 포함되어 있습니다.

지원 프로토콜: Medium adding/exchanging, Subculture, Passaging, Cell observation/counting

지원 소모품: 최대 100개의 T-75 flask

메인 유닛: Dispenser, 4채널 Liquid handler

구성 모듈: 자체 개발 Automation Incubator, Plate hotel, Barcode reader, 컬러 Microscope, Tilting deck, Suction unit, 6축 Robotics arm

지원 프로토콜: Medium adding/exchanging, Subculture, Passaging, Cell observation

96-to-48, 48-to-12 Subculture 같은 작업을 지원합니다.

장비명: HARMONi-NK

구성 모듈: Automation Incubator, Barcode reader, 라인 스캔 Microscope, Tilting deck, Vision deck, 자동 원심분리기, 6축 Robotics arm

지원 프로토콜: Medium adding, exchanging

프로젝트명: CELLi

장비 내부 환경을 ISO 기준 Class A 수준으로 유지하고, 외부 오염물질 유입을 막는 Isolator 프레임으로 구성됩니다.

내부 환경 모니터링은 파티클 카운터와 TSA 플레이트를 이용하며, 장비 내부/외부 간 세포와 소모품 전달은 Pass box를 통해서만 이루어집니다.

모듈내용 요약
리퀴드 핸들러ADP를 이용해 Media change, Subculture 수행. Well plate 간 정량 이동 구현
디스펜서큰 용량의 Media를 정량 공급. Suction 노즐과 Sonication 세척 장치 포함
자동 CO₂ 인큐베이터Plate, Flask 등 소모품 자동 수납. Carousel, Automation door, handling robot 내장
자동 이미징 장치Area scan 또는 Line scan camera로 전체 이미지 저장/분석
콜로니 피커Single cell에서 배양된 cell을 다른 well plate로 이송. 개발 진행 중
디캐퍼로봇 암과 연동해 C-Tube 뚜껑을 열고 닫는 유닛
오비탈 셰이커인큐베이터 내부에 설치하는 진탕 배양 장치
Suction unit사용 완료된 media를 흡인 폐기하고, 알코올 Sonication으로 멸균

상세 스펙은 별도 문의 또는 PDF 자료를 통해 확인 가능합니다.

아니오. 기본적으로 자동화 공정 안에 포함되어 앞뒤 공정과의 연계를 고려해 개발되기 때문에, 별도 모듈로 판매하지는 않습니다.

용도에 따라 다양한 Microscope를 맞춤 제작할 수 있습니다.

기본형: 4x 해상도 컬러 Area scan 카메라를 탑재합니다.

속도형: Line scan 카메라를 사용해 1개 플레이트 전체를 약 1분 안에 스캔할 수 있습니다.

저장된 이미지는 리뷰, DB화, 이력 관리, 역추적이 가능하고, 콜로니 관찰을 위한 Phase contrast 필터와 특정 지점 관찰을 위한 Live scan도 지원합니다.

네. 개발 장비는 내부를 Class A 수준 환경으로 유지하고, TSA Plate와 파티클 카운터를 이용한 환경 모니터링을 지원합니다.

알코올 소독, 건열, 습열, VHP 훈증 등 여러 방법을 적용할 수 있지만, 자동화 장비 특성상 제어장치가 노출되는 경우가 많아서 VHP 훈증 방식을 채용합니다.

CELLi 환경 모니터링/관리 요소는 다음과 같습니다.

  • VHP 멸균 시스템
  • UV 램프
  • PMS 파티클 카운터
  • PMS TSA 샘플러

자체 제작한 SW를 사용하여 장비 제어와 프로토콜 관리를 수행합니다.

항목내용
제어 SW자체 제작 SW 사용
UI/프로토콜고객사가 원하는 형식으로 변경 가능
규정 대응21 CFR Part 11에 맞는 전자서명, 기록, 보안 정책 준수
AI 기능세포 인식, Confluency 계산 가능
